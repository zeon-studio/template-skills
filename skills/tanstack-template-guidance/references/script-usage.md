# Script Usage

This skill explains the `pnpm` commands and custom Node scripts available in this TanStack Start template.

> [!IMPORTANT]
> **Script Verification Required:** Because this skill is used across multiple templates, the commands below are **JUST EXAMPLES**. Scripts may be missing, renamed, or do different things. **You MUST ALWAYS read `package.json` (and list `scripts/`) before running anything or assuming its behaviour.**

## Example pnpm Commands (Verify Before Use)

### `pnpm dev`
Starts the local dev server (Vite, or Rsbuild depending on the template).
- The TanStack Router plugin watches `src/routes/` and regenerates `routeTree.gen.ts` on every file add/rename.
- Templates with a theming pipeline also run a generator in watch mode so `theme.json` edits hot-reload.

### `pnpm build`
Builds for production — client bundle plus the server build used for SSR.
- Generator scripts (theme, search index) normally run **before** the bundler so generated assets exist at build time.

### `pnpm start` / `pnpm serve` / `pnpm preview`
Runs the built output locally. Because Start is a full-stack framework, this boots a **server**, not just a static file host. Check which name the template uses.

### Content-collections builds
If the template uses `content-collections`, its build step runs as part of dev/build and regenerates typed content imports. New markdown files may require a dev-server restart to appear.

## Generated files — never edit by hand

- **`src/routeTree.gen.ts`** — regenerated by the router plugin
- **`generated-theme.css`** (or similar) — produced from `theme.json`
- **`search.json`** — produced by a content-scanning script
- **`.content-collections/`** or equivalent — generated content output

Edit the *source* (route files, `theme.json`, markdown) instead.

## Deployment note

TanStack Start builds against a runtime adapter for the host — Node, Cloudflare Workers, Netlify, Railway and others are supported. The target is configured in the bundler/Start config, so check it before assuming the build output is a plain static site. **Sitepins-managed content still requires a rebuild/redeploy to appear** unless the template loads content at runtime.

## Common Mistakes / What NOT to do

- **DO NOT** run `npx vite dev` directly. It bypasses the template's generator scripts and produces broken CSS variables or a stale search index. Use `pnpm dev`.
- **DO NOT** hand-edit generated files; they're overwritten on the next run.
- **DO NOT** assume `pnpm build` yields a static site — Start produces a server build unless the template explicitly prerenders.
